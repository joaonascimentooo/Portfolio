# Portfólio - João Nascimento

Portfólio pessoal feito com Next.js, React e TypeScript, pronto para deploy na Vercel.

## Rodar localmente

```bash
npm install
npm run dev
```

Depois abra `http://localhost:3000`.

## Deploy na Vercel

1. Envie este projeto para um repositório no GitHub.
2. Entre em `https://vercel.com/new`.
3. Importe o repositório.
4. Use as configurações padrão da Vercel para Next.js e clique em Deploy.

## Onde editar

- Texto, projetos e links: `app/page.tsx`
- Visual dark e responsividade: `app/globals.css`
- Imagem principal: `public/joao-avatar.png`
